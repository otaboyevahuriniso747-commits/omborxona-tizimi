Loyiha Ishi Taqdimoti

"Omborxona" - Mahsulotlar qoldig'ini aqlli nazorat qilish tizimi

1. Kirish va Loyiha Maqsadi

Ushbu loyiha ishi zamonaviy korxonalar, do'konlar va omborxonalar uchun mahsulotlar zaxirasini avtomatlashtirilgan tarzda nazorat qilish tizimini yaratishga qaratilgan. Tizimning asosiy maqsadi – ombordagi mahsulotlar qoldig'i haqida aniq va tezkor ma'lumot berish hamda zaxirasi tugab borayotgan mahsulotlar haqida o'z vaqtida ogohlantirishdir.

Asosiy Vazifalar:

  • Mahsulotlarni tizimga tezkor kiritish, tahrirlash va o'chirish.
  • Joriy qoldiqni vizual va real vaqtda ko'rsatib borish.
  • Har bir mahsulot turi uchun shaxsiy minimal ogohlantirish chegarasini belgilash.
  • Qidiruv paneli orqali kerakli ma'lumotni darhol topish.

2. Foydalanilgan Texnologiyalar

Veb-ilova ma'lumotlarni xavfsiz va internet yo'q paytida ham tez ishlaydigan qilish maqsadida to'liq "Client-side" (Mijoz tomoni) usulida ishlab chiqilgan:

Semantik struktura

3. Tizimning Asosiy Imkoniyatlari

Asosiy Panel (Dashboard)

Tizim markaziy oynasida 3 ta ko'rsatkich doimiy hisoblanib turadi va interaktiv sonlar bilan ko'rsatiladi: Jami ro'yxatga olingan mahsulotlar, Kam qolganlari va Tugaganlari.

Avtomatik Holat (Status) Beligilanishi

Mahsulotlar miqdoriga qarab ularning maqomi o'zgaradi va jadvalda oson ilg'ash uchun ranglarga ajratiladi:

  • Yaxshi — Zaxira xavfsiz darajada.
  • Kam qolgan — Zaxira ogohlantirish (minimal) chegarasiga yetgan.
  • Tugagan — Mahsulot qoldig'i 0 ga teng.

Modal Oyna Orqali Boshqaruv

Yangi mahsulot kiritish yoki eskisini tahrirlash qulay, markazda qalqib chiquvchi sahifasiz "Modal" oyna orqali bajariladi.

4. Dastur Kadi (Algoritm) Namunasi

Jadval qatorlari avtomatik chizilishi jarayonida mahsulot qoldig'iga qarab vizual rangni aniqlovchi JavaScript mantiqi:

// product.quantity - mahsulotning joriy miqdori
// product.min - foydalanuvchi belgilagan minimal chegara

let statusHtml = '';

if (product.quantity <= 0) {
    statusHtml = '<span class="status-badge status-danger">Tugagan</span>';
} else if (product.quantity <= product.min) {
    statusHtml = '<span class="status-badge status-warning">Kam qolgan</span>';
} else {
    statusHtml = '<span class="status-badge status-normal">Yaxshi</span>';
}

// Keyin ushbu statusHtml jadval ichiga (DOM ga) joylanadi

5. Xulosa

Ushbu yaratilgan "Omborxona" nazorati dasturi biznes egalari va omborchilar uchun har qanday qog'ozbozlikdan voz kechishga va o'z hisob-kitoblarini xatosiz avtomatlashtirishga yordam beradi. Tizim tezkor ishlaydi hamda mahsulotlar yetishmovchiligining oldini olishda muhim ko'makchi vazifasini bajaradi.
